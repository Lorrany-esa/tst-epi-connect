
TST Distribuidora - Plataforma Web

Plataforma e-commerce e institucional desenvolvida para a TST Distribuidora de EPIs, Ferramentas e Material Industrial. O projeto traz uma interface moderna, responsiva e otimizada para atuar no modelo B2B/B2C (Atacado e Varejo), facilitando a navegação por catálogos, consulta de Certificados de Aprovação (CA) e solicitação rápida de orçamentos.

🧪 Tecnologias Utilizadas

React (Vite / TanStack Router)

TypeScript

Tailwind CSS (Design system responsivo e estilização customizada)

Lucide React (Pacote de ícones)

🛠️ Funcionalidades Principais

Cabeçalho Fixo & Navegação Dinâmica: Barra de topo com informações institucionais, integração direta com WhatsApp e contatos de vendas.

Catálogo de Produtos e Kits: Exibição clara de equipamentos de proteção (capacetes, óculos, luvas, botas) e ofertas do mês.

Consulta de CA: Seção dedicada para validação dos Certificados de Aprovação de EPIs.

Solicitação de Cotações: Botões de CTA direcionados para faturamento empresarial e atendimento rápido via WhatsApp.

Layout Adaptável: UI totalmente responsiva, ajustada tanto para desktop quanto para dispositivos móveis.
